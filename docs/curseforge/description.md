# Run Recap Forever

**Your dungeon run at a glance.** After the last boss, Run Recap shows a summary of the whole run: every boss, who got which loot, and the facts that made the run.

## Features

- **Works by itself.** Enter a dungeon and Run Recap starts recording. After the last boss, a short success moment plays and the summary opens. Nothing to set up.
- **Bosses & loot.** Every boss with the minute in the run and the fight duration. Below each boss, the loot and the player who got it, in class colours. Loot from normal enemies is listed under "Trash". If the source is not certain, it is marked as "probably".
- **Rolls.** Hover an item to see who won it. Hold Shift to see every roll: need, greed, pass and the numbers.
- **Run facts.** Duration, bosses, wipes and deaths per player. Plus your own balance: looted gold plus the vendor value of your loot, minus the repair costs of the run.
- **Highlights.** The four most remarkable moments of the run, for example the toughest boss, the luckiest roll, the fastest kill or the best item.
- **All dungeons of WoW Forever**, including the new Forever dungeons. Multi-wing dungeons (Scarlet Monastery, Dire Maul, Stratholme, Blackrock Spire) count per wing.
- **Two looks.** Native Blizzard style, or Run Recap's dark & gold.
- **Smart about leaving.** Released as a ghost after a wipe? The run keeps going. Hearthed out to a vendor? The run pauses and continues when you come back.
- **10 languages:** English, German, French, Spanish, Portuguese, Italian, Russian, Korean, Simplified and Traditional Chinese.

## Commands

- `/recap` – open the last summary
- `/recap demo` – preview with a made-up run
- `/recap options` – options
- `/recap tour` – restart the introduction

## Good to know

Run Recap only sees what your own client sees. Loot of other players shows up while you are nearby and in the group. Gold, vendor value and repair costs are your own.

# Run Recap Forever (Deutsch)

**Dein Dungeon-Run auf einen Blick.** Nach dem Endboss zeigt Run Recap eine Zusammenfassung des ganzen Runs: jeder Boss, wer welche Beute bekommen hat und die Fakten zum Run.

- **Läuft von allein.** Betritt einen Dungeon, und Run Recap zeichnet mit. Nach dem Endboss folgt ein kurzer Erfolgsmoment, dann öffnet sich die Übersicht.
- **Bosse & Beute.** Jeder Boss mit Minute im Run und Kampfdauer, darunter die Beute und wer sie bekommen hat, in Klassenfarbe. Beute von normalen Gegnern steht unter „Trash“.
- **Würfe.** Über einem Item siehst du, wer es gewonnen hat. Mit Umschalt siehst du alle Würfe.
- **Fakten zum Run.** Dauer, Bosse, Wipes und Tode pro Spieler. Dazu deine Bilanz: Gold plus der Händlerwert deiner Beute, minus die Reparaturkosten.
- **Highlights.** Die vier spannendsten Momente des Runs.
- **Alle Dungeons von WoW Forever**, auch die neuen Forever-Dungeons.
- **Zwei Darstellungen:** Blizzard-Optik oder Run Recap dunkel & gold.
- **Komplett auf Deutsch.**

Befehle: `/recap`, `/recap demo`, `/recap options`, `/recap tour`
