Fonts shipped with Run Recap Forever (SIL Open Font License 1.1, see OFL-cinzel.txt):

Cinzel-Bold.ttf              Cinzel, (c) The Cinzel Project Authors.
                             Static Bold (wght 700) instance of the variable font, subset to Latin incl. Latin-1
                             and Latin Extended-A. Used for the title of the success banner.

Everything else (windows, options, the banner's smaller lines) uses the game's own font
(Friz Quadrata on Latin clients), which is not shipped.
Cinzel has no Cyrillic or CJK: Russian, Korean and Chinese clients use the game font for the banner title too.

Source: https://github.com/google/fonts
