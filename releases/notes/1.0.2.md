Run Recap 1.0.2 – runs per character

- **Your runs per character:** `/recap` and the minimap button now show the last run of the character you are playing. On an alt you no longer see your main's run. Runs from before this update can't be assigned and are shown for every character. The last 20 runs are kept per character.
- **New option "Show runs of all characters"** (off by default): shows the account's last run as before; the recap then shows whose run it is.

---

Run Recap 1.0.2 – Runs pro Charakter

- **Deine Runs pro Charakter:** `/recap` und der Minimap-Button zeigen jetzt den letzten Run des Charakters, den du gerade spielst. Auf dem Twink siehst du nicht mehr den Run deines Mains. Runs von vor diesem Update lassen sich keinem Charakter zuordnen und werden bei jedem Charakter gezeigt. Gespeichert werden die letzten 20 Runs pro Charakter.
- **Neue Option „Runs aller Charaktere anzeigen“** (Standard aus): zeigt wie bisher den letzten Run des Accounts; die Übersicht zeigt dann, von wem der Run ist.
