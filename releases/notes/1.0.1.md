Run Recap 1.0.1 – bug fixes

- **Rolls on items with "of"-style names:** on some clients (German in particular, e.g. "[Mantel von Doan]") the roll line was cut in the wrong place, so rolls ended up under made-up player names and the run facts listed extra "players" under Deaths. Fixed – and runs saved with this error are repaired automatically.
- **Deaths list:** at most 5 players, the rest as "+N more" (hover it for everyone). The run facts no longer run into the highlights in big groups.

---

Run Recap 1.0.1 – Fehlerbehebungen

- **Würfe auf Items mit „von“ im Namen:** z. B. bei „[Mantel von Doan]“ wurde die Würfelzeile an der falschen Stelle getrennt – die Würfe landeten unter ausgedachten Spielernamen und bei „Tode“ standen zusätzliche „Spieler“. Behoben, und bereits gespeicherte Runs mit diesem Fehler werden automatisch repariert.
- **Tode-Liste:** höchstens 5 Spieler, der Rest als „+N weitere“ (Maus drüber zeigt alle). Bei großen Gruppen laufen die Fakten zum Run nicht mehr in die Highlights.
